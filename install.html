Installation help

Current version v0.2.18-beta · Release files and notes on GitHub

Freelance Easy is a desktop app. The installers are hosted on GitHub; the download buttons on this site point straight at the current release. Both versions ask you to sign in with Google the first time and to choose a folder for your invoice data.

Mac

  • Requirements: a Mac with an Apple chip (M1 or later). Intel Macs aren't supported. To check: Apple menu → About This Mac.
  • Download: Freelance-Easy.dmg, about 154 MB. Open it and drag Freelance Easy into Applications.
  • First open: the app is signed and notarized by Apple, so macOS may only show its usual "downloaded from the internet — are you sure you want to open it?" dialog. Click Open.
  • Updates: the app checks GitHub for new versions and offers to install them.

Windows

  • Requirements: Windows 10 or 11, 64-bit.
  • Download: Freelance-Easy-Setup.exe, about 134 MB.
  • The warning you'll see: the installer isn't code-signed yet, so Windows doesn't recognise the publisher and shows a blue Windows protected your PC screen when you run it. If you want to continue, click More info, then Run anyway. This is Windows SmartScreen doing its job with an unknown publisher; we're working on signing.
  • If there is no "Run anyway": some Windows 11 PCs have Smart App Control turned on, which blocks unsigned apps outright rather than warning. Until the installer is signed, Freelance Easy can't run on those PCs unless Smart App Control is turned off — a decision we'd rather you make deliberately than for us.
  • Updates: the app checks GitHub for new versions and offers to install them.

Where your data goes

During setup you choose a folder. Everything the app stores — your clients, invoices, PDFs, attachments — lives inside it. Back up that folder the way you back up your other work. If you ever want to leave, the folder is yours: the database is an ordinary SQLite file and the invoices are ordinary PDFs.

Uninstalling

Mac: drag the app to the Trash. Windows: Settings → Apps → Freelance Easy → Uninstall. Neither removes your data folder; delete it yourself if you want it gone.
